# Commandes & Permissions

## Commandes

### `/ultratackstats` (alias : `/uts`)

Commande principale du plugin.

| Sous-commande | Description | Permission |
|---|---|---|
| `reload` | Recharge `config.yml` et réenregistre les listeners en conséquence | `ultratackstats.reload` |

**Utilisation :**
```
/uts reload
/ultratackstats reload
```

## Permissions

| Permission | Description | Défaut |
|---|---|---|
| `ultratackstats.reload` | Permet au joueur d'utiliser `/uts reload` | `op` |
