# Commands & Permissions

## Commands

### `/ultratackstats` (alias: `/uts`)

Main plugin command.

| Subcommand | Description | Permission |
|---|---|---|
| `reload` | Reloads `config.yml` and re-registers listeners accordingly | `ultratackstats.reload` |

**Usage:**
```
/uts reload
/ultratackstats reload
```

## Permissions

| Permission | Description | Default |
|---|---|---|
| `ultratackstats.reload` | Allows the player to use `/uts reload` | `op` |
